สิ่งที่ปรับปรุง

  • ✓ KPI Strip ด้านบน (แพ็กเกจ / ยอด / รอบบิลถัดไป / Add-ons)
  • ✓ Stacked bar แสดงสัดส่วนค่าใช้จ่ายแบบเห็นภาพ
  • ✓ จัดกลุ่ม Add-ons เป็น 4 หมวด (Operations / Finance / Marketing / Platform)
  • ✓ Progress bar ของช่วงเวลาแพ็กเกจ + เหลือกี่วัน
  • ✓ Quick Actions panel (เปลี่ยนแพ็กเกจ, ต่ออายุ, Invoice, ฯลฯ)
  • ✓ Status Timeline แบบ vertical พร้อมสีและผู้ทำรายการ
  • ✓ ค้นหา / กรอง Add-on ภายใน Modal
  • ✓ Hover เห็นปุ่มลบ Add-on ทันที (ลดคลิก)

ข้อเสนอแนะเพิ่มเติม

  • • เพิ่มแท็บ "Audit Log" ดูประวัติแบบเต็มและ filter ได้
  • • ปุ่ม "Impersonate" สำหรับ admin เข้าดูในมุมเจ้าของ
  • • Health Score (การชำระเงิน, การใช้งาน) ที่แถบ KPI
  • • แสดงสถานะ Payment ล่าสุดและ Dunning warning
  • • Confirm modal ก่อนเปลี่ยน status (กัน mis-click)
  • • Inline edit Add-on quantity / discount
  • • Export รายละเอียดเป็น PDF / CSV
  • • Keyboard shortcut (Esc=ปิด, Ctrl+E=Edit, Tab navigation)
