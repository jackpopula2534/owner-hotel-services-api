สิ่งที่ปรับปรุง

  • ✓ KPI 5 ช่อง: ทั้งหมด/ใช้งานได้/ระงับ/ปิดใช้งาน/หมดอายุเร็วๆ นี้
  • ✓ Avatar รูปวงกลม + สีตาม role (ดูเร็วขึ้น)
  • ✓ Role แสดงภาษาไทย + icon ตาม category
  • ✓ Column "โรงแรม / Tenant" — แยกข้อมูลให้รู้ว่าผู้ใช้ของโรงแรมไหน
  • ✓ Last login แบบ relative time + Online indicator + จำนวนครั้ง
  • ✓ Filters ขั้นสูง: บทบาท (multi-select) / โรงแรม / Last login
  • ✓ Filter chips แสดง filter ที่ active
  • ✓ Bulk select + actions (เปิดใช้, ระงับ, อีเมล, ลบ)
  • ✓ Quick actions แสดงตอน hover row (ดูรายละเอียด/Impersonate/อีเมล/3-dot)
  • ✓ Add User / Import CSV / Export CSV ที่ header
  • ✓ Sort by column + page size selector
  • ✓ Suspended/Disabled row จะดู dim + แสดงเหตุผล/เวลา

ข้อเสนอแนะเพิ่มเติม:

  • • Side panel ดูรายละเอียด user (ไม่ต้องเปลี่ยนหน้า) + Activity Log
  • • Reset Password / Send Magic Link จาก dropdown
  • • Saved filters (Filter Presets) เช่น "Tenant Admin หมดอายุเร็วๆ นี้"
  • • Audit trail ใครเปลี่ยน status, เมื่อไหร่
  • • Confirm Dialog ทุก action (เหมือนหน้า Subscription)
  • • Keyboard shortcuts: / โฟกัสค้นหา, j/k เลื่อน, Esc clear selection
